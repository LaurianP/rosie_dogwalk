## Principles
- The quote calculator is the page: a customer gets a clear, itemized price in seconds, and the owner can quote a client on the phone with it just as fast.
- Keep it plain and readable: pricing rules sit in one obvious block at the top of the script so the owner can change rates without hunting through the code.
## Constraints
- Single-file web app (one `index.html` with embedded CSS and JS); no backend, no database, no login, no external API calls, no frameworks.
## Definition of done
- Opening `index.html` straight from disk works in a current browser, on a phone and on a desktop, with no console errors.
- Changing any input updates the quote immediately, and the total matches a hand calculation for a few typical bookings.
